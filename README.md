# Novel Dialogue  

A module for displaying images in the style of visual novels.  

> **Warning!** Image preprocessing (background removal) is required.  

## Roadmap  
- Expression menu  
- Multiple easily switchable images per character.  

## Usage  
- Double-click to open the image for all players  
- Double-click to close the image only for yourself
